## Install

1. Download `gmail-pr-threads-vVERSION.zip` below and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and pick the `gmail-pr-threads` folder (or click **Reload** if an older version is already loaded from the same folder).
4. In **Details → Extension options**, save a GitHub personal access token (fine-grained: read-only *Pull requests*, *Commit statuses* and *Contents*; classic: `repo`).
5. Reload Gmail.
